# Security Policy

## Experimental Status
AIriProject is an experimental open-source framework for AI-assisted development. As it deals with autonomous operations and code modification, safety is our primary concern.

## Reporting a Vulnerability
We strongly encourage security researchers and users to report any issues that could compromise the safety or integrity of the development environment.

### What to Report
- Potential secret/credential leakage in AI prompts or logs.
- Risks of unsafe automation or "looping" behaviors.
- Bypasses of the Governance Layer (e.g., unauthorized file mutations).
- Vulnerabilities in the Claim Boundary routing protocol.

### How to Report
Please **DO NOT** create a public GitHub issue for security-related vulnerabilities. Instead, contact the maintainer directly at:

**[SECURITY_CONTACT_PLACEHOLDER]**

We will acknowledge your report and work to resolve the issue as soon as possible.

## Data Privacy Warning
Never post personal data (PII), real-world financial records, or active API keys in public issues or pull requests. Any contributions containing sensitive information will be immediately deleted.

## Response SLA
As this is an early-stage experimental project, we do not currently have a formal Service Level Agreement (SLA) for security responses, but we prioritize safety-critical reports.
